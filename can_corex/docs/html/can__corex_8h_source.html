149 /* ============================================================
150 * Time base type configuration
151 *
152 * Primary time base:
153 * - used by core CAN RX/TX logic
154 * - expressed by CCX_TIME_t / CCX_MAX_TIMEOUT
155 * - public unit is always milliseconds
156 *
157 * High-resolution time base:
158 * - used by HR-aware modules such as ISO-TP and bus monitor
159 * - expressed by CCX_HR_TIME_t / CCX_HR_MAX_TIMEOUT
160 * - public unit is microseconds when HR is enabled
161 * - public unit falls back to milliseconds when HR is disabled
162 *
163 * Configuration is width-based and unsigned only.
164 * Signed tick types are intentionally not supported because the library relies
165 * on wraparound subtraction for timeout arithmetic.
166 *
167 * If no custom width macro is defined, uint32_t is used by default.
168 * ============================================================ */
