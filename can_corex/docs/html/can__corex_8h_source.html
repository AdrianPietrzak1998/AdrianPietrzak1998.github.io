122 /* ============================================================
123 * Time base type configuration
124 *
125 * Primary time base:
126 * - used by core CAN RX/TX logic
127 * - expressed by CCX_TIME_t / CCX_MAX_TIMEOUT
128 * - public unit is always milliseconds
129 *
130 * High-resolution time base:
131 * - used by HR-aware modules such as ISO-TP and bus monitor
132 * - expressed by CCX_HR_TIME_t / CCX_HR_MAX_TIMEOUT
133 * - public unit is microseconds when HR is enabled
134 * - public unit falls back to milliseconds when HR is disabled
135 *
136 * Configuration is width-based and unsigned only.
137 * Signed tick types are intentionally not supported because the library relies
138 * on wraparound subtraction for timeout arithmetic.
139 *
140 * If no custom width macro is defined, uint32_t is used by default.
141 * ============================================================ */
