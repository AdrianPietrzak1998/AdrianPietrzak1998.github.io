55 /* ============================================================
56 * ISO 11898-1 BUS-OFF recovery timing
57 *
58 * Condition:
59 * 128 x 11 recessive bits = 1408 bits
60 *
61 * Classic CAN constants are expressed directly in milliseconds because they
62 * do not benefit from the HR domain. Short recovery delays can still be
63 * expressed through CCX_BUS_RECOVERY_US(us). Values up to 3 ms use the HR
64 * timebase when available; longer values are tracked in the base time domain.
65 * The _MS suffix is kept for API stability.
66 * ============================================================ */
