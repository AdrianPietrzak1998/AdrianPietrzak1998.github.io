Detailed Description

Bus monitor configuration and state.

Provides automatic bus-off detection and recovery with configurable retry strategy. Recovery process has two phases:

  1. Active recovery: Attempts recovery up to max_recovery_attempts times
  2. Grace period: After max attempts, waits successful_run_time before trying again
